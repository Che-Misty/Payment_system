# Payment System

Консольная система денежных переводов между пользователями, реализованная на Go. Проект демонстрирует работу со структурами, методами, интерфейсами коллекций, обработкой ошибок, горутинами, каналами и синхронизацией доступа к данным.

## Возможности

* Создание пользователей с балансом
* Пополнение баланса
* Снятие средств с проверкой достаточности баланса
* Переводы между пользователями
* Очередь транзакций
* Обработка ошибок при переводах
* Конкурентная обработка транзакций с использованием горутин
* Использование каналов для передачи задач воркерам
* Синхронизация горутин через `sync.WaitGroup`
* Защита баланса пользователей от состояния гонки с помощью `sync.Mutex`

## Запуск

### Требования

* Go 1.25+

### Установка

```bash
git clone https://github.com/USERNAME/payment-system.git
cd payment-system
go run .
```

## Версии проекта

### v1 — Базовая работа с пользователями

Добавлено:

* Структура `User`
* Метод `Deposit`
* Метод `Withdraw`
* Проверка достаточности средств
* Создание пользователей и выполнение операций с балансом

Цель: изучение структур и методов в Go.

---

### v2 — Система транзакций

Добавлено:

* Структура `Transaction`
* Структура `PaymentSystem`
* Хранение пользователей в `map`
* Очередь транзакций в `slice`
* Методы:

  * `AddUser`
  * `AddTransaction`
  * `ProcessingTransactions`
* Обработка ошибок при переводах

Цель: работа со структурами данных и бизнес-логикой переводов.

---

### v3 — Конкурентная обработка

Добавлено:

* Горутины-воркеры
* Канал для передачи транзакций
* `sync.WaitGroup`
* Параллельная обработка очереди переводов

Цель: изучение конкурентности в Go.

---

### v4 — Защита от Data Race

Добавлено:

* `sync.Mutex` в структуру `User`
* Блокировка операций `Deposit`
* Блокировка операций `Withdraw`

Цель: обеспечение потокобезопасного изменения баланса пользователей.
